# Ответ интегратору — Evolution Console, круг 3 (06.08.2026)

В PR #7 добавлен следующий продуктовый срез Console `0.16.0`: понятное управление
общими правилами и знаниями поверх уже существующего канонического механизма Shared
Genes. Новый движок и второй кабинет не создавались.

## Что изменилось

- Раздел `Shared Genes` открывается как задача **«Общие правила и знания»**.
- Слева показаны две понятные группы: **«Общие правила»** и **«Общие знания»**.
- Для выбранного элемента Console показывает текущую версию и точный список агентов,
  которые его используют.
- До любого действия виден человеческий impact: **«Изменение затронет N агентов»**.
- Путь показан тремя шагами: **Настроить → Проверить → Применить**.
- Техническая двусторонняя карта `Shared Gene ↔ agent` сохранена, но перенесена под
  раскрытие **«Техническая карта Shared Genes»**.
- RU/EN реализованы одним словарём; layout адаптирован для узкого окна.

## Действия не подменены макетом

- **«Подготовить изменение»** вызывает прежний `openClassChangeForGene()` и открывает
  канонический `Agent Cabinet` для точного consumer-агента.
- Кнопка закрыта, пока нет `data_mode=PRODUCTION`, полного current snapshot и
  production-eligible стандарта.
- **«Проверить в Evolution Lab»** активируется только для реального candidate, в
  `candidate_bundle` которого закреплён этот `Shared Gene`, и только при полном точном
  change context текущего registry snapshot.
- Применение по-прежнему проходит через существующие гейты Evolution Loop. UI не
  создаёт test evidence, activation или success самостоятельно.
- Host patch и межустройственная атомарная идемпотентность trusted publish остаются
  закрытыми, как описано в круге 2.
