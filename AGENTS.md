# Инструкция для ИИ-ассистента (Codex и др.)

Ты работаешь над **Extella Plugins** — магазином плагинов внутри Extella Desktop
(оверрайд верхней панели). Команда: **Элла** (CMO, продукт, тексты, дизайн — принимает
работу) и **Анвар** (платформа, хост, визард, серверные эксперты). Продукт выходит
сначала на русском; язык интерфейса переключается RU/EN.

## Репозиторий и структура

- `toolbar/public/plugins_manager.html` — ВСЯ витрина одним файлом (~6700 строк:
  стили, разметка, данные-каталоги, логика). Главный файл проекта.
- `toolbar/public/plugin-chat.html`, `plugin-form.html` — окна плагинов (чат/форма).
- `toolbar/src/core/*.js` — хост-слой (роутер, api, auth, реестр), `toolbar/src/panels/*.js` —
  панели хоста (marketplace, library, activity-center, github-add…).
- `toolbar/build.js` — сборка всего в `toolbar/build/toolbar.js` (в git НЕ входит).
- `HANDOFF/toolbar.js` и `toolbar/toolbar.js` — готовые сборки в git (обновлять при каждом пуше!).
- `device/` — служба фоновых задач (python, порт 8799). `modules/library/` — SPA Библиотеки.
- `PORTABILITY.md` — карта «что работает из коробки» и правила. Прочитай её целиком.
- `toolbar/DEV_HANDOFF.md` — технический контракт с ядром (не патчить ядро v6; эксперты
  через `skBridge('etb_run_expert',…)` с `global:true`; KV-каталоги шардированы).

## Рабочий цикл (обязателен)

1. Правка исходников (НИКОГДА не правь `toolbar/build/*` или готовые сборки руками).
2. `cd toolbar && node build.js` — сборка сама прогонит двух стражей:
   синтаксис инлайн-скриптов (vm.Script) и канон имён. Красный страж = чинить, не обходить.
3. Проверка в превью: статический сервер из `toolbar/build/`
   (`python3 -m http.server 4600 --directory toolbar/build`), открыть `plugins_manager.html`.
   Мост KV мокается в консоли: `window.skKvGet=()=>Promise.resolve(null); window.skKvSet=()=>Promise.resolve(true);`
   Язык: `setLang('ru'|'en')`. Вкладки: `setc('programs'|'models'|'skills'|'cli'|'knowledge'|'services'|'agents'|'desktop')`.
4. Коммит в `main` + push (пуши по ходу работы — норма команды; сообщения коммитов по-русски, содержательные).
5. **При каждом пуше** пересобери и закоммить обе готовые копии:
   `cp toolbar/build/toolbar.js HANDOFF/toolbar.js && cp toolbar/build/toolbar.js toolbar/toolbar.js`.
6. Стейдж для приёмки Эллы: `cp toolbar/build/toolbar.js ~/Library/Application\ Support/extella-desktop/toolbar.js`.
   **Перезапуск Extella делает только Элла** (⌘Q) — сам не перезапускай приложение.

## Каноны (нарушение = переделка)

### Имена сущностей
- **Конструктор** (EN: Wizard) — панель «Мой компьютер» и создание/настройка агентов. Слово «Визард» в RU-текстах запрещено (страж уронит сборку).
- **Композитор** — ТОЛЬКО имя Студии Композитора (видимая вещь Анвара). Невидимый фоновый
  сборщик — без персонажа: «Extella найдёт и добавит», кнопка «Найти и добавить», статус «Ищу и собираю…».
- Запрещены: Строитель, Фабрика (кроме «Фабрика комиксов» — это имя HF-демо), ассистент/помощник/бот/юзер.
- Правило: видимым вещам — имена, невидимым процессам — глаголы.

### Тексты (голос Эллы)
- Просто, по-человечески, лёгкий юмор уместен; ты-форма («вставь», «получишь»); без канцелярита.
- Понятно человеку, впервые открывшему приложение. Запрещённый жаргон: мост, PID, VPS,
  локалхост, крон, реестр, эмбеддер, векторизация, «искомый», remote и т.п.
- Штампы запрещены: «в один клик» (0 вхождений — держать), «сама/сам» как акцент
  самостоятельности («найдёт и добавит сама» → «найдёт и добавит»).
- Ошибка ВСЕГДА говорит, что делать. «Идёт в фоне» можно писать только при настоящем
  таймауте, не при любой ошибке. Пустой список при ошибке загрузки — запрещён
  (различай «пусто» и «не смог проверить»).
- Кнопка = точное обещание клика («Найти и добавить», не «Передать»).

### Дизайн
- Радиус единый 4–6px (токен `--r:5px`), границы 1px вместо теней (тени — только оверлеи).
- Iconoir-иконки (`#ic-*`, хелпер `_ico`), эмодзи — только аватары агентов. Без капса, без градиентов-заливок.
- Шрифты: Source Serif 4 (редакционные акценты: герои, диалоги), Source Sans 3 (UI,
  заголовки разделов), JetBrains Mono (метки источников). Фон `#FAF9F5`, акценты бронза `#C57E33`/петроль.
- Порядок полки: лид-подводка (15px, обычный текст, ≤100 знаков, «что здесь + что делать»)
  → пунктирная плитка «+ Добавить» (класс `tf_skip` — фильтр её игнорирует) → герои bento → каталог с чипами.

### Язык (i18n)
- Витрина: RU — исходный, EN — DOM-walker `_walkTranslate` по словарю `I18N_EN`
  (ключ = ТОЧНАЯ русская строка) + `I18N_RX` регэкспы + покомпонентный перевод «A · B» +
  MutationObserver для модалок. Новую русскую строку ВСЕГДА сопровождай парой в словаре.
- Окна плагинов и панель активности: `T(ru,en)` по `localStorage.etb_lang`; язык также
  едет в `etb_init` полем `lang` — сохраняй это поле при правках отправителей.
- Лейблы форм из `plugins/*.json` переводятся картой `FORM_I18N_RU` в plugin-form.html.

### Портируемость
- Никаких личных ID/путей. Агенты — только динамическое определение; известный ID — лишь запасной.
- Фича с внешним компонентом (порт 8765/8799, системные плагины, эксперты) обязана
  честно деградировать: приглушение + причина. Образец — системные ярлыки стола.
- Всё должно работать у любого пользователя с GitHub. Сверяйся с PORTABILITY.md.

## Границы и безопасность

- **Чужие репозитории не пушить** (extella-marketplace-pack и др.) — только читать; правки туда — патчем в сообщении Анвару.
- Наружу (мессенджеры, письма) ничего не отправляется автоматически — только черновики, отправляет человек.
- Токены/ключи не хранить в коде и не логировать. Авторизация — динамическая из сессии.
- Кредиты Extella не жечь: агентов вызывать только когда без этого нельзя.
- Деплой коллегам — через HANDOFF → marketplace-pack, только по прямому слову Анвара.

## Как работает Элла

Тестирует руками, приносит симптомы и скриншоты — по одному. Твоя работа: воспроизвести,
найти корень, починить, доказать (превью/скрин/обход DOM), запушить. Не спорь с её
вкусом на тексты и UX — она права чаще; но проверяй факты и честно говори, если
формулировка обещает то, чего продукт не делает.
