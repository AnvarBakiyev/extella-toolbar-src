## Дополнение 27.07, вечер — решение Эллы по персоне

**Персона интервью = «Мастер»** (канон, UX_CANON §4). «Проектировщик» не утверждён —
верни «Мастер» там, где переименовал (extella-plugin.json / install.py / instructions агента).
Причина: имя уже живёт во всех экранах («Пройти интервью с Мастером», «расскажи Мастеру»,
«Мастер Extella» в шапке чата) — два имени у одного персонажа создают путаницу, которую
мы месяц вычищали. Проверка: grep -c "Проектировщик" по репо → 0.

И забери из ветки ella/wizard-canon-merge оставшиеся коммиты (EN-пары + ты-форма новых
строк) — они там есть, твой git log смотрел устаревший fetch.
