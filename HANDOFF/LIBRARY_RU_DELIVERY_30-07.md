**В интерфейс НЕ заведено** — по твоему же порядку: `index.ts` по-прежнему знает только

## Что проверено автоматически (все девять файлов, ноль провалов)

- каждый EN-ключ имеет русскую пару; лишних ключей нет (кроме форм множественного числа);
- ни одного слова из твоего запретного списка §2 («токен», «деплой», «сессия» и т.д.);
- ни одной «вы»-формы — «ты» везде;
- все `{{подстановки}}` на месте и совпадают с EN;
- у каждого счётчика три формы.

## Три формы множественного числа — это не ошибка

В русском «1 агент / 2 агента / 5 агентов» — поэтому в каждом словаре со счётчиком
появились ключи `*_few`, которых нет в EN (там форм две). Схема как в твоём образце
`rules.json`: `_one` / `_few` / `_other` (родительный множественного лежит в `_other` —
i18next сам падает на него для «многих»). Файлы с добавленными `_few`:
agents, devices, experts, teams, concepts.

## Решения по ходу — глянь при вычитке

1. **`Token` → «ключ доступа»** ровно по глоссарию: экран «Ключи доступа», колонка «Ключ»,
   «Новый ключ» / «Скопировать ключ» / «Отозвать».
2. **`KV Store` → «Хранилище»**, ключ там — «ключ записи», рядом «Значение». «Ключ-значение»
   в интерфейс не попало.
3. **`master agent` → «ведущий агент»** (teams). В глоссарии слова нет; «мастер» рядом с
   персоной Конструктора читался бы как она. «Без ведущего» на карточке.
4. **`backend` → «на платформе»** (teams: «составы задаются на платформе»).
5. **Поясняющие строки экранов (§3)**: легли в существующие ключи подзаголовков —
   отдельного ключа «лид-строки» в EN-файлах нет. «Эксперты» и «Концепты» — твои черновики
   в `list.subtitle`/`subtitle.userActive`, «Ключи доступа» — в `subtitle`. Если лид должен
   быть отдельным элементом ПЕРВЫМ на экране — это правка компонентов, скажи, заведём
   отдельной задачей.
6. **Счётчики в подзаголовках без плюрализации** (`subtitle` — один ключ в EN, без форм):
   обошёл формой «устройств: {{count}}» / «ключей: {{count}}» — она верна при любом числе.
   Менять на три формы = добавлять ключи и в EN, решай при вычитке.
7. **`Terminate` (фоновая задача) → «Остановить»**, не «Завершить» — обещание кнопки честнее.
8. **`Studio / Library` (brand)** → «Студия» / «Библиотека».
