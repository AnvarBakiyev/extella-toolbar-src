# Дизайн-стандарт каталожной вкладки (Extella Toolbar)

Единый шаблон для ВСЕХ каталожных вкладок: **Сервисы** (Программы/Инструменты/Сервисы/Приложения), **Модели**, **Навыки**, **Знания**, **Агенты**. Цель — одинаковая структура и вид, разный только контент. Любой новый каталог собирается по этому шаблону.

## Аудит (15.07): система УЖЕ единая
Все каталожные карточки используют один компонент **`.stile`** в сетке **`.mshelf`**; герои — **`_bentoHTML`**; разделители — **`.sect_hdr`**; лид — **`.sk_lead`**. Выброс был один (секция «Приложения» использовала `ws_lead` из воркспейса) — исправлен на `sk_lead`.

## Шаблон вкладки (порядок сверху вниз)

1. **Герой (bento)** — `_bentoHTML(TYPE_ED.<tab>.heroes)`. 1 крупная + 2 малых карточки, задают тон вкладки. (Исключение: «Программы» — спотлайт `programsSpotlight()` + строка поиска; допустимо, т.к. это витрина готовых решений.)
2. **Лид-строка** — `<div class="sk_lead" style="grid-column:1/-1">…одна фраза, что это и зачем…</div>`. НЕ `ws_lead` (это класс воркспейса).
3. **(Опц.) Фильтр/под-навигация** — чипы `.cat_chip` (активный `.cat_chip.on`). Пример: под-навигация Сервисов `_svcBar`, категории программ `_featCatBar`.
4. **Секции** — каждый смысловой блок открывается разделителем:
   `<div class="sect_hdr"><span class="sect_title">Название</span><span class="sect_line"></span></div>`
   затем сетка `<div class="mshelf"> …карточки… </div>`.
5. **«Добавить …»** — при уместности тайл-приглашение через фабрику (`addTileHTML` / dashed `.stile`).
6. **Состояния** — загрузка `_loadingHTML('Загружаю…')`; пусто `_emptyHTML(icon, text)` ИЛИ `.sk_lead`; ошибка — та же `.sk_lead` с ⚠.

## Карточка `.stile` (единый компонент)
```
<div class="stile" style="--acc:<цвет-категории>">
  <span class="st_chip">🏷 категория · метаданные</span>   // тип, ★, метки (💻/🖥/✓)
  <div class="st_title">Название</div>
  <div class="st_fact">Короткое описание (1 строка)</div>
  <div class="st_foot" style="justify-content:space-between;align-items:center">
    <button class="st_btn" onclick="…">Установить / ▶ Открыть</button>
    <a href="…" target="_blank" style="font-size:11px;color:var(--tx3)">GitHub ↗</a>
  </div>
</div>
```
- **`--acc`** — цвет акцента по КАТЕГОРИИ (левый бордер/чип). Программы/сервисы — `BIZ_ACC[cat]`; приложения — фиолетовый `#7A3FA0` (единый для всей категории приложений). Внутри одной категории карточки одноцветны.
- Кнопки — только `.st_btn` (primary) и вторичная ссылка `var(--tx3)`. Никаких кастомных кнопок.
- Установленное: чип `· ✓ установлено`, кнопка → `▶ Открыть` (+ `🗑` где есть удаление).

## Правила
- **Один класс карточки** — `.stile`. Не создавать новые card-компоненты; отличается только контент чипа/кнопок.
- **Сетка** — только `.mshelf` (или `.mshelf_capped` для длинных списков).
- **Цвета** — из палитры категорий (`BIZ_ACC`/`TYPE_ED`), не хардкодить хекс в разметке (кроме единого цвета категории).
- **Тексты** — бизнес-язык, короткие; лид ≤ 1–2 строк.
- **Не тащить** классы других разделов (`ws_*` воркспейса, `wx-*` кокпита) в каталоги.
