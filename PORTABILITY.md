# Портируемость: что получает новый пользователь «из коробки»

Цель: человек ставит тулбар из этого репозитория — и **всё** (программы, базы знаний,
модели, сервисы, студии) работает у него, без ручной донастройки и без привязки
к чьему-то личному компьютеру или аккаунту.

Статус на 20.07.2026. Колонка «из коробки» = после `git pull && ./install.sh`.

## Работает из коробки ✅

| Что | Почему работает |
|---|---|
| Витрина целиком (каталог, полки, поиск, тексты RU/EN) | Всё в одном файле сборки, без внешних зависимостей |
| Установка курированных программ и HF-моделей | Детерминированные пути: GitHub/HF напрямую + платформенные эксперты с `global:true` |
| Чат и формы плагинов | Язык/тема/токен приезжают из витрины; агент определяется динамически (`_resolveAgent`, личные ID вычищены) |
| Живые каталоги (инструменты, MCP, программы) | Читаются из общих KV платформы, шардированы |
| Базы знаний — движок | `kp_resolver` сам ставит Ollama + модель эмбеддингов при первой установке базы |
| «Найти и добавить» (фоновый сборщик) | Основной агент-сборщик + фолбэк на агента сессии пользователя |

## НЕ работает из коробки ⚠ — нужен единый установщик

| Дыра | Симптом у нового пользователя | Чей ход |
|---|---|---|
| **Системные плагины** (Студия Композитора, Студия языков, Команда, Второй пилот, визард Конструктора) не ставятся этим репо | Ярлыки стола приглушены с пометкой «ещё не установлена» (честно, но мертво) | Анвар: включить раздачу реестра в установщик |
| **Служба фоновых процессов** (порт 8799) не ставится/не стартует | «Что работает в фоне» и панель задач пусты навсегда | Анвар: автозапуск службы или её установка |
| **Регистрация экспертов пака** (`kp_*`, `cap_*`, 87 шт.) — отдельный `install.py` из marketplace-pack | Без неё не работают формы-карточки, базы знаний, фабрика инструментов | Анвар: подтвердить — глобальны ли эксперты для всех аккаунтов или нужен прогон per-user; если per-user — включить в установщик |
| **Коллизия файлов баз знаний** (кириллица → `_`, 22 базы → 14 файлов) | Базы затирают друг друга («Здоровье» ⟷ «Управление проектами») | Анвар: патч `kp_install_pack`/`kp_ask` (передан 18.07) |
| Хост молчит при `open` несуществующего плагина | Клик «в пустоту» без объяснения (витрина теперь подстраховывает, но хост тоже должен отвечать) | Анвар: ответ хоста «плагин не установлен» |

## Правила, чтобы дыры не появлялись снова

1. **Никаких личных ID/путей в коде.** Агенты — только динамическое определение;
   допустим известный ID с фолбэком (как `BUILDER_ID` → агент сессии).
2. **Каждая фича, зависящая от компонента вне репо, обязана честно деградировать:**
   приглушённая кнопка + объяснение, а не тихая смерть (образец — системные ярлыки стола).
3. **Все правки — только через этот репозиторий.** Готовые сборки (`HANDOFF/toolbar.js`
   и `toolbar/toolbar.js`) пересобираются при каждом пуше; локальные копии — только стейдж.
4. Сборка защищена стражами (`build.js`): синтаксис инлайн-скриптов и канон имён.

## Определение готовности к релизу

Новый пользователь на чистом Маке: `git clone` → `./install.sh` (или установщик Анвара) →
перезапуск Extella → **все семь ярлыков стола живые, установка из каждого раздела
работает, «Что работает в фоне» показывает процессы**. Пока это не так — релиза нет.
