# Портируемость: что получает новый пользователь «из коробки»

Цель: человек ставит тулбар из этого репозитория — и **всё** (программы, базы знаний,
модели, сервисы, студии) работает у него, без ручной донастройки и без привязки
к чьему-то личному компьютеру или аккаунту.

Обновлено 20.07.2026 по полному аудиту (3 прохода: хардкоды · установка с нуля ·
карта зависимостей каждой фичи). Колонка «из коробки» = после `git clone && ./install.sh`.

## Работает из коробки ✅

| Что | Почему работает |
|---|---|
| Витрина целиком (каталог, полки, поиск, тексты RU/EN, панель активности) | Один файл сборки; авторизация и userId полностью динамические (refresh → cookie → DOM) |
| Установка без Node | `install.sh` ретайрен (заглушка с маркером `EXTELLA_STANDALONE_INSTALLER_RETIRED=1`) и HANDOFF не использует. Установка идёт из пака; `HANDOFF/toolbar.js` — рабочая копия чата-владельца, релизным артефактом не является (§11) |
| Установка курированных программ и HF-моделей | Детерминированные пути + платформенные эксперты `global:true` |
| Чат и формы плагинов | Язык/тема/токен из витрины; агент — динамически; личные ID вычищены (в т.ч. второй, `agent_XwZ…` из установки навыков — 20.07) |
| «Найти и добавить» | Сначала агент СЕССИИ пользователя, спец-сборщик — только запасной (20.07) |
| Живые каталоги, базы знаний (движок ставится сам), история запусков агентов, операции динамических CLI-тулов | KV-шлюз расширен на `agent_runs:`/`cap_*_manifest` — две фичи, мёртвые по конструкции, ожили (20.07) |
| Зависание облака | На все запросы к api.extella.ai — таймаут 90с (раньше — вечные спиннеры) |

## Правила, чтобы дыры не появлялись снова

1. **Никаких личных ID/путей в коде.** Агенты — только динамика; известный ID — лишь запасной.
2. **Фича с внешним компонентом обязана честно деградировать**: приглушение + причина, не тишина.
3. **«Идёт в фоне» разрешено говорить только при таймауте** — не при любой ошибке.
4. **Пустой список при ошибке загрузки — запрещён**: различать «пусто» и «не смог проверить».
5. **Все правки — только через репозиторий**; готовые сборки пересобираются при каждом пуше.
6. Сборка защищена стражами (`build.js`): синтаксис инлайн-скриптов, канон имён.
