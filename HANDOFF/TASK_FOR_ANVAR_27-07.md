## Дополнение 27.07, вечер — решение Эллы по персоне

**Персона интервью = «Мастер»** (канон, UX_CANON §4). «Проектировщик» не утверждён —
верни «Мастер» там, где переименовал (extella-plugin.json / install.py / instructions агента).
Причина: имя уже живёт во всех экранах («Пройти интервью с Мастером», «расскажи Мастеру»,
«Мастер Extella» в шапке чата) — два имени у одного персонажа создают путаницу, которую
мы месяц вычищали. Проверка: grep -c "Проектировщик" по репо → 0.

И забери из ветки ella/wizard-canon-merge оставшиеся коммиты (EN-пары + ты-форма новых
строк) — они там есть, твой git log смотрел устаревший fetch.

### Два бага в твоём коде, которые я починила
1. **Сломанные иконки help-модалок.** В `HELP` были Python-escape'ы: `icon: '\U0001F9E9'`.
   JS такой синтаксис не понимает — пользователю печаталось буквально «U0001F9E9»
   рядом с заголовком (Элла прислала скрин). Полей `icon` теперь нет (канон §3: без эмодзи
   в хроме). Если будешь возвращать иконки — только `\u{1F9E9}` или спрайт.
2. «Вы»-формы в текстах help-модалок — переписаны на «ты».

### Решение Эллы: сущности «Композитор» больше нет
Функционал сохранён полностью, убрано только имя-персонаж (канон: видимым вещам — имена,
невидимым процессам — глаголы). Переименовано:
- Конструктор: ссылка на первом экране → «быструю сборку», панель «Студия Композитора» →
  «Быстрая сборка», help → «Как работает быстрая сборка»;
- витрина: «блоки Композитора» → «блоки автоматизаций», «Стало блоком Композитора» →
  «Подключено к автоматизациям».

**Не возвращай имя** ни в UI, ни в новых экранах. Внутренние id (`extella_composer_studio`,
`?app=composer`) не тронуты — контракт цел.
