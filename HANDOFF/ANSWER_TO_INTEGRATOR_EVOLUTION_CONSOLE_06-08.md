- Карточки разделены на четыре класса: `automation`, `system`, `installed_app`, `probe`.
- В парк попадают семь объявленных автоматизаций; восемь системных поверхностей не смешиваются с клиентскими продуктами.

- Версия видимой поверхности: `0.14.0`.

## Нужна одна поправка стандарта состояния

Текущий `automation.state_reader` ещё недостаточен для универсального вызова. В нём есть `expert` и `method`, но нет точного объекта параметров Expert:

- `ps_call`, `rec_call`, `tgt_call` принимают маршрут в параметре `method`;
- `law_call` принимает его в параметре `route`;
- дополнительные параметры диспетчеров также различаются (`args_json`, `kwargs_json`, `body_json`).

Console не будет зашивать исключение по имени продукта. Просьба добавить в шаблон и готовые паспорта точный объект:

```yaml
state_reader:
  expert: "law_call"
  params:
    route: "/x/status"
    body_json: "{}"
  schema: "law_status.v1"
  execution_device: "..."
  data_device: "..."
  evidence: "exact_target"
```

Для `ps_call`, например:

```yaml
params:
  method: "read_state"
  args_json: "[]"
  kwargs_json: "{}"
```

Требования к `params`: точный закрытый объект, только JSON-скаляры, без токенов/секретов, с машинным гейтом. После этого Console сможет вызывать Expert через `targets: [execution_device]`, проверять доказательство точного таргета и оставлять незнакомые поля результата отсутствующими.

Пока этой формы нет, контракт показывается в технических сведениях, а состояние остаётся честно неизвестным; действия закрыты. Турагентство с одним localhost-service контрактом также остаётся без удалённого чтения состояния.

## Что требуется от host-интеграции trusted publish

Маршруты уже в toolbar и fail-closed. Для фактической публикации хост должен предоставить ровно два метода в `ETB.evolutionAdapter`:

- `loadTrustedPublishContext({host_context})` — read-only контекст;
- `publishTrustedDraft({request, host_context})` — публикация с суточной идемпотентностью, проверкой трёх evidence refs на стороне действия, read-back, квитанцией и rollback.

Аккаунт и токен берутся только из host session. Из iframe приходят лишь snapshot fence, correlation id и закрытый request contract. До появления адаптера кнопка публикации не должна показываться.
